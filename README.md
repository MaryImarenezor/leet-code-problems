# leet-code-problems

Hello! This Github repo contains all of the Leetcode problems I did over the past few years! I decided to save my work in this repo to use for future resources and for safe keeping purposes

I really wanted to hone in on mastering 4 languages: Python, Java, JS, and C++. I've taken classes about these different programming languages before, and the concepts behind them, and I really want to expand upon these languages, not just to keep myself sharp or to not forget syntax, but to also understand computer science concepts and get the big idea of things.
im using roadmap.sh, w3schools and geeksforgeeks as a resource in re-inforcing these languages while also explain the computing concepts via these programming languages. I'm also using Grind 75 to look for leetcode problems that are in my level.
I mostly do leetcode problems during by spring, winter, and summer breaks, and the goal is that by the end of the breaks, I would've mastered these languages, deepen my understanding of computer science concepts, get myself ready for opportunities related to these 4 languages, and develop my own projects with these languages. I also want to use my freetime to FINALLY get started on LeetCode since I've been shying away from it for some time
